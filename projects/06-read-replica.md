# Project 6: Read Replica Simulation

## Goal

Understand read replica behavior and replication lag.

## Tasks

1. Set up streaming replication (local Docker or managed service trial)
2. Write to primary, read from replica
3. Measure lag under load
4. Document: what happens if app reads from replica immediately after write?
